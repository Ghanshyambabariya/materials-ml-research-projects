# Tool-wear model efficiency: research plan

## Goal
Reduce model fitting time while keeping held-out-tool prediction RMSE within 5% of the 300-tree Random Forest baseline.

## Evidence already in this repository
- Public Vicomtech dataset: 2,054 cleaned rows, 13 independent tools, 150 features.
- Original grouped test: Random Forest RMSE 51.0834, R² 0.8680, MAE 33.4742.
- Baseline is from the existing tool-wear benchmark. The new comparison uses the original string-form tool IDs and split seed, then measures the baseline and three alternatives on the same runner.

## Experiment
1. Split whole tools (not rows) into development and test groups using seed 42.
2. Reserve a separate set of development tools for validation.
3. Fit four models and select the fastest whose validation RMSE is at most 5% above the baseline.
4. Refit the baseline and selected model on all development tools; evaluate the held-out test tools once.
5. Save metrics, training time, tool IDs and the outcome of both goals.

The report is generated by scripts/compare_tool_wear_models.py and will appear under benchmarks/ after execution.

## Interpretation
A faster model could make retraining and iteration cheaper. This does not demonstrate faster machining, reduced scrap, or improved factory output. Tool-wise test results do not establish transfer to another machine or material.

Sources: [Vicomtech dataset](https://github.com/Vicomtech/dataset-machine-tool-wear), [multisensor tool-wear research](https://doi.org/10.1007/s00170-025-15472-4).
